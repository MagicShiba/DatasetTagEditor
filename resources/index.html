显示如何编辑标签的说明
1. 所有显示图像共有的标签以逗号分隔的形式显示。
2. 应用更改后，每张显示图像中的所有标签会被替换。
3. 如果将某些标签改为空白，它们将被删除。
4. 如果在末尾添加标签，它们会被添加到文本文件的末尾/开头。
5. 在按下「保存所有更改」按钮之前，更改不会应用到文本文件。
示例 A.
 原文本 = "A, A, B, C" 通用标签 = "B, A" 编辑标签 = "X, Y"
 结果 = "Y, Y, X, C" （B→X，A→Y）
示例 B.
 原文本 = "A, B, C" 通用标签 = "（无）" 编辑标签 = "X, Y"
 结果 = "A, B, C, X, Y" （将 X 和 Y 添加到末尾（默认））
 结果 = "X, Y, A, B, C" （将 X 和 Y 添加到开头（勾选「前置附加标签」））
示例 C.
 原文本 = "A, B, C, D, E" 通用标签 = "A, B, D" 编辑标签 = ", X, "
 结果 = "X, C, E" （A→"", B→X, D→""）
